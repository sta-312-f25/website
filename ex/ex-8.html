Diagnostics and Transformations

Problem 1

Given the following small dataset:

\[\mathbf{y} = \begin{bmatrix}5\\8\\12\\20\\30\end{bmatrix}\]

\[\mathbf{X} = \begin{bmatrix}1&1\\1&2\\1&3\\1&4\\1&5\end{bmatrix}\]

a) Fit the linear regression model \(y = \beta_0 + \beta_1 x + \varepsilon\) and calculate the residuals \(\hat{\varepsilon}_i\) for each observation.

b) Calculate the leverage \(h_i\) for each observation using the formula \(h_i = H_{ii}\) where \(\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\). You may use R for the matrix calculations.

c) Calculate the standardized residuals \(r_i = \frac{\hat{\varepsilon}_i}{\hat{\sigma}\sqrt{1-h_i}}\) for each observation.

d) Calculate the studentized residuals \(t_i = \frac{\hat{\varepsilon}_i}{\hat{\sigma}_{(i)}\sqrt{1-h_i}}\) for each observation. For this, you’ll need to fit the model 5 times, each time leaving out one observation, to get \(\hat{\sigma}_{(i)}\).

e) Which observation(s), if any, would you flag as potential outliers based on the studentized residuals?

Problem 2

Using the same data from Problem 1:

a) Calculate Cook’s distance for each observation using the formula: \[D_i = \frac{r_i^2}{p} \cdot \frac{h_i}{1-h_i}\] where \(p = 2\) (number of parameters) and \(r_i\) are the standardized residuals from Problem 1.

b) Would any observations be considered influential using the rule of thumb \(D_i > 4/n\)?

c) Refit the model excluding the most influential point. How much do \(\hat{\beta}_0\) and \(\hat{\beta}_1\) change? Does this confirm the Cook’s distance calculation?

Problem 3

In this problem, you’ll investigate the impact of non-constant variance on confidence interval coverage and how transformations can help.

Simulation setup: - Sample size: n = 30
- Generate x from \(N(0, 1)\)
- True model: \(y = 5 + 1.5x + \varepsilon\) - Number of simulations: 5000

Instead of generating your \(\varepsilon\sim N(0,1)\) let’s have it depend on \(x\) like this like in Problem 5 from the last exercise:

sigma <- exp(x / 2)  
epsilon <- rnorm(n, 0, sigma)

a) Write a simulation function that:

  1. Generates data from the true model
  2. Fit lm(y ~ x)
  3. Constructs a 95% confidence interval for \(\beta_1\)
  4. Checks whether the interval contains the true slope (1.5)
  5. Returns TRUE or FALSE

b) Calculate the coverage probability. What did you obtain? Is it close to 95%?

c) For one simulated dataset, create two plots side by side: - Left: Scatterplot of y vs. x with fitted line - Right: Residuals vs. fitted values plot

Describe what you see. What assumption is violated?

d) Now repeat the simulation, but this time: 1. Generate the same data 2. Fit a model that transforms \(y\) using the log. 3. Exponentiate your confidence interval and compare whether this contains 1.5 4. Calculate the 95% CI coverage for \(\beta_1\)

What coverage probability do you obtain now? How does it compare to part (b)?

e) For the same simulated dataset from part (c), create the same two plots but using log(y) as the response. How do the diagnostics look now?

Problem 4

Consider a dataset where the relationship between y and x is quadratic: \(y = 2 + 3x - 0.5x^2 + \varepsilon\) where \(\varepsilon \sim N(0, 1)\).

Generate data with n = 100 and x from uniform(0, 5).

a) Fit a linear model lm(y ~ x) and create a partial regression plot. Since there’s only one predictor, this is just a scatterplot of y vs. x with the fitted line. Does the relationship look linear?

b) Create a residuals vs. fitted values plot. What pattern do you see? What does this suggest about the model specification?

c) Now fit a quadratic model lm(y ~ x + I(x^2)). Create the residuals vs. fitted values plot for this model. How does it compare to part (b)?

d) Calculate the IQR of x. Using the quadratic model, find:

  • The predicted y at the 25th percentile of x
  • The predicted y at the 75th percentile of x
  • The change in predicted y for an IQR increase in x

e) Interpret this IQR change. Why is this more useful than trying to interpret individual coefficients in a polynomial model?

Problem 5

Using the same data generation as Problem 4 (quadratic relationship):

a) Fit three models: 1. Linear: lm(y ~ x) 2. Quadratic: lm(y ~ x + I(x^2)) 3. Natural spline with 4 df: lm(y ~ ns(x, df = 4))

Create a plot showing:

  • The data points
  • All three fitted curves
  • The true relationship (generate a grid of x values and calculate the true y without error)

Which model comes closest to the true relationship?

b) Calculate the \(R^2\) for all three models. Which has the highest \(R^2\)? Does this necessarily mean it’s the best model?

c) For the natural spline model, what are the knot locations? (Hint: use attr(ns(x, df = 4), "knots"))

d) Create a visualization showing the four spline basis functions. Describe how they differ from each other and note their behavior at the boundaries.

Problem 6

In this problem, you’ll investigate what happens when we fit a linear model to data that requires a log transformation of the response.

Simulation setup: - True model: \(\log(y) = 1 + 2x + \varepsilon\) where \(\varepsilon \sim N(0, 0.5)\) - This means: \(y = \exp(1 + 2x + \varepsilon)\) - Sample size: n = 60 - Generate x from uniform(0, 3) - Number of simulations: 2000

a) For a single simulated dataset, create a 2×2 grid of diagnostic plots: 1. Top left: y vs. x with fitted line from lm(y ~ x) 2. Top right: Residuals vs. fitted for lm(y ~ x) 3. Bottom left: log(y) vs. x with fitted line from lm(log(y) ~ x) 4. Bottom right: Residuals vs. fitted for lm(log(y) ~ x)

Describe what you observe about constant variance in each case.

b) Using the incorrect model lm(y ~ x), create a Q-Q plot of the residuals. Do the residuals appear normally distributed? What pattern do you see?

c) Using the correct model lm(log(y) ~ x), create a Q-Q plot of the residuals. How does this compare to part (b)?

d) The true model is \(\log(y) = 1 + 2x + \varepsilon\). When we fit lm(log(y) ~ x) and obtain coefficients \(\hat{\beta}_0\) and \(\hat{\beta}_1\), we can back-transform to get predictions on the original scale: \[\hat{y} = \exp(\hat{\beta}_0 + \hat{\beta}_1 x)\]

For a single dataset, calculate the predicted y at x = 1.5 using: - The incorrect model: lm(y ~ x) - The correct model with back-transformation: exp(predict(lm(log(y) ~ x))) - The true expected value: \(E[y|x=1.5] = \exp(1 + 2(1.5) + 0.5^2/2) = \exp(4.125)\)

(Note: The extra \(0.5^2/2\) term appears because \(E[\exp(\varepsilon)] = \exp(\sigma^2/2)\) when \(\varepsilon \sim N(0, \sigma^2)\))

Which model’s prediction is closer to the truth?

Problem 7

This problem explores Type I error inflation when we test for non-linearity and add terms based on significance tests, compared to using flexible modeling from the start.

Simulation setup: - True model: \(y = 2 + 3x + \varepsilon\) where \(\varepsilon \sim N(0, 4)\) (purely linear!) - Sample size: n = 50 - Generate x from uniform(0, 5) - Number of simulations: 3000

Strategy 1: Test-then-add approach 1. Fit lm(y ~ x) 2. Test if adding \(x^2\) is significant at \(\alpha = 0.05\) by fitting lm(y ~ x + I(x^2)) and checking if the p-value for the \(x^2\) coefficient is < 0.05 3. If significant, use the quadratic model; otherwise use the linear model 4. Test \(H_0: \beta_1 = 3\) (the true linear coefficient) at \(\alpha = 0.05\) using the chosen model 5. Record if you reject \(H_0\) (this is a Type I error since \(\beta_1 = 3\) is true)

Strategy 2: Natural spline by default 1. Fit lm(y ~ ns(x, df = 3)) (always use this flexible model) 2. To test if the linear coefficient equals 3, you need to be creative: fit lm(y ~ x) and test \(H_0: \beta_1 = 3\) 3. Record if you reject \(H_0\) at \(\alpha = 0.05\)

a) Implement Strategy 1. What proportion of the time do you: - Find the quadratic term “significant” (even though the true model is linear)? - Reject \(H_0: \beta_1 = 3\) (Type I error)?

b) The nominal Type I error rate should be 5%. Is the Type I error rate from Strategy 1 close to 5%? If not, explain why testing for significance and then using that result to build your model inflates Type I error.

c) Implement Strategy 2. What is the Type I error rate when testing \(\beta_1 = 3\) using this approach?

d) Create a visualization showing one simulated dataset with: - The data points - True linear relationship (as a line) - Fitted quadratic model from Strategy 1 (when it happens to be “significant”) - Fitted natural spline from Strategy 2

Which estimated curve is closer to the truth?

e) Now repeat both strategies with the true model being: \(y = 2 + 3x + 0.2x^2 + \varepsilon\) (slightly quadratic).

Calculate for both strategies: - Power to detect that \(\beta_1 \neq 3\) (now the linear model is wrong, so rejection is good!) - Average estimated value of \(\beta_1\) from the linear model lm(y ~ x)

Which strategy performs better at detecting the model misspecification?

f) Reflect on the trade-off: Strategy 1 (test-then-add) inflates Type I error when the relationship is truly linear, but Strategy 2 (always use splines) might be overly complex. What would you recommend to a researcher in practice?
